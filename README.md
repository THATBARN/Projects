# Balance Checker

## Requirements

1. Python Virtual Environment:

        python3 -m venv venv
        source venv/bin/activate
        pip install -r requirements.txt

2. [Chromedriver](https://chromedriver.chromium.org/downloads).

3. Cron Job.

4. Telegram Bot Token and Chat ID.

5. Credentials.
